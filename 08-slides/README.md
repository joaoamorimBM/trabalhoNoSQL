# Slides finais

O deck **não é feito separado por cada um**. O fluxo é:

1. Cada integrante preenche o `conteudo.md` da sua pasta (texto, falas, fontes, imagens).
2. Quando todas as pastas estiverem prontas no `main`, o João Pedro gera o deck único a partir desses
   arquivos (mesmo visual para todos) e salva aqui.
3. Todo mundo revisa o próprio trecho e a equipe faz um ensaio cronometrado (máx. 15 min).
